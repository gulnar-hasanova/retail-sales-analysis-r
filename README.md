# Retail Sales Analysis in Azerbaijan (R)

## Description
This project analyzes retail sales data in Azerbaijan using R. It focuses on data cleaning, exploratory data analysis (EDA), anomaly detection, and data visualization.

## Objectives
- Analyze retail sales performance
- Identify anomalies in price and quantity
- Explore patterns and trends in the dataset
- Present insights using visualizations

## Tools & Technologies
- R
- dplyr
- ggplot2

## Dataset
The dataset contains retail sales information, including product names, prices, quantities, and store types.

## Analysis Steps
1. Data cleaning and preprocessing  
2. Exploratory Data Analysis (EDA)  
3. Anomaly detection using statistical methods  
4. Data visualization  

## Results
- Detected inconsistent values in price and quantity fields  
- Identified outliers in sales data  
- Visualized key trends and patterns

This project was completed as part of a Data Analytics training program (Code Academy).
